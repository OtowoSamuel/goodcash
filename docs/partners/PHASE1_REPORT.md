## Changed from the plan (and why)

1. **Webhook retries run on the existing 10-minute schedule**, not every minute: a 1-minute schedule would list KV
   ~2,900 times a day, over the free KV allowance. First delivery is still immediate.
2. **Per-partner rate limits are one setting for all partners** (600/min): Cloudflare rate-limit bindings are fixed
   in `wrangler.toml`. Per-wallet create limit reuses the existing limiter.
3. **The web app's bank picker and step bar were not moved into `@goodcash/react`**: moving them would restyle the
   live app. The React package has its own; the web app is untouched.
4. **Widget wallets:** the partner's own wallet (host signing), a wallet already in the browser, and Magic's Wallet
   Kit panel (WalletConnect, Coinbase, email) for everyone else. Phone browsers are only offered wallets that can work
   there (see `apps/widget/README.md`). The panel needs the Magic and WalletConnect public keys at build time and
   `pay.goodcash.xyz` allowed in both dashboards.
5. **OpenAPI is hand-written**, not generated from zod (most `/v1` checks are not zod schemas).
6. **Allowed sites must be exact origins**; wildcard sub-domains are not supported (matters for AI app builders).
7. **Fee ledger built** (option A): one entry per paid live cash out; a partner is only credited if the payout
   partner really charged the fee.

## Commands for you (when you decide to go ahead)

```bash
# 1. Webhook secret encryption key (once; you never see it)
cd services/orders && openssl rand -base64 32 | npx wrangler secret put PARTNER_SECRETS_KEY
# 2. Turn the API on: set PARTNER_API_ENABLED = "true" in services/orders/wrangler.toml, then
cd services/orders && npx wrangler deploy
# 3. First partner (prints keys once)
node scripts/partners.mjs create --name "Acme Games" --origins https://acme.game --apps com.acme.game --fee 0.5
# 4. Widget site (separate Pages project), then attach pay.goodcash.xyz in the Cloudflare dashboard
cd apps/widget && npm run build && npx wrangler pages deploy dist --project-name goodcash-widget
# 5. Packages (after creating the free npm organisation "goodcash")
cd packages/sdk && npm publish --access public
cd packages/react && npm publish --access public
```

Secrets to set (names only): `PARTNER_SECRETS_KEY`. New binding: `RATE_LIMITER_PARTNER` (in `wrangler.toml`).
